# Calendar Memo (Obsidian Plugin)

메모잇(Memoit) 스타일의 끊김 없는 월간 캘린더 그리드 UI와 옵시디언 네이티브 Live Preview 팝오버 편집기를 결합한 옵시디언 캘린더 메모장 플러그인입니다.

## 주요 기능

- **무한(연속) 스크롤 캘린더 & 키보드 내비게이션**
  - 이전 달/다음 달 경계 없이 상하로 자연스럽게 이어지는 연속 스크롤 그리드
  - 방향키(`↑`, `↓`, `←`, `→`) 탐색, `T` 오늘 이동, 상단 `<` `>` 및 연·월 빠른 점프
  - 리본 아이콘 클릭 한 번 또는 명령어 단축키로 캘린더 뷰 즉시 열기/닫기
- **메모잇 스타일 팝오버 + 옵시디언 네이티브 Live Preview 에디터**
  - 날짜 셀에서 `Enter` 또는 **더블클릭** 시 해당 셀 위치에 플로팅 편집 창 오픈
  - 옵시디언 기본 마크다운 편집기 임베드(`[[위키링크]]`, 체크박스, 하이라이트 등 지원)
  - `Cmd/Ctrl + Enter`로 저장 후 즉시 닫기 (`ESC` / 바깥 클릭 닫기 지원)
  - 셀 미리보기에서 팝오버를 열지 않고도 체크박스 클릭 토글 가능
- **엑셀형 2D 선택 · 복붙 · 셀 배경색 · Undo/Redo**
  - `Shift + 방향키` 또는 마우스 드래그로 2D 직사각형 다중 선택
  - `Cmd/Ctrl + C`: 캘린더 내부에서는 2D 배치 유지 붙여넣기, 외부 메모장 등에서는 비어 있는 날짜를 제외한 `[YYYY-MM-DD]\n내용` 형식으로 출력
  - `Cmd/Ctrl + V` 덮어쓰기, `Delete`/`Backspace` 일괄 삭제, 8색 파스텔 셀 배경색 팔레트, `Cmd/Ctrl + Z / Y` 그리드 Undo/Redo
- **폴더 탭 전환 & 커스텀 날짜 포맷**
  - 상단 탭 바에서 여러 폴더 탭(`+ 폴더 추가`)을 등록하고 클릭 또는 `Alt + 1~9`로 즉시 전환
  - 옵시디언 데일리 노트 호환 커스텀 날짜 포맷(`YYYY-MM-DD`, `YYYY/MM/YYYY-MM-DD`, `YYYY-MM-DD (ddd)` 등) 및 실시간 양방향 동기화
  - 빈 파일 생성 방지 및 내용을 전부 지웠을 때 `.md` 파일 자동 삭제
- **오프라인 한국형 달력 & 반복 일정 오버레이**
  - 외부 API 없이 오프라인으로 대한민국 공휴일·대체공휴일·주요 기념일·음력 표시 (`@hangukit/holidays-core` + `korean-lunar-calendar` 내장, 2027년 이후 자동 산출)
  - 사용자 커스텀 휴일·기념일(양력/음력) 추가 지원
  - 매일 / 매주(요일) / 매월(일자) / 영업일 기준(매 영업일, 매월 N번째·마지막 영업일) 반복 일정 관리 (현재 탭 전용 / 모든 탭 공통 선택 가능)

## 개발 및 빌드

```bash
npm install
npm run build
npm test
```

로컬 옵시디언 볼트에 빌드 결과물(`main.js`, `manifest.json`, `styles.css`)을 자동 배포하려면 프로젝트 루트에 `.env` 파일을 생성해 볼트 경로를 지정하세요:

```env
OBSIDIAN_VAULT_PATH=/path/to/your/obsidian-vault
```
