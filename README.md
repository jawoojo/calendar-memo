# Calendar Memo (Obsidian Plugin)

메모잇(Memoit) 스타일의 끊김 없는 월간 캘린더 그리드 UI와 옵시디언 네이티브 Live Preview 팝오버 편집기를 결합한 옵시디언 캘린더 메모장 플러그인입니다.

## 주요 기능

- **무한(연속) 스크롤 캘린더 & 키보드 내비게이션**
  - 이전 달/다음 달 경계 없이 상하로 자연스럽게 이어지는 연속 스크롤 그리드
  - 방향키(`↑`, `↓`, `←`, `→`) 탐색, `T` 오늘 이동, 상단 `<` `>` 및 연·월 빠른 점프
  - 리본 아이콘 또는 단축키 명령어(`캘린더 메모장 열기 / 화면으로 이동`, `캘린더 메모장 열기/닫기 (토글)`) 지원
- **메모잇 스타일 팝오버 + 옵시디언 네이티브 Live Preview 에디터**
  - 날짜 셀에서 `Enter` 또는 **더블클릭** 시 해당 셀 위치에 플로팅 편집 창 오픈
  - 옵시디언 기본 마크다운 편집기 임베드(`[[위키링크]]`, 체크박스, 이모지 접두어 하이라이트 `==🔵...==` 등 지원)
  - 소·중·대 크기 프리셋 클릭 전환 및 테두리/코너 드래그 리사이즈 (선호 크기 자동 저장)
  - `Cmd/Ctrl + Enter`로 저장 후 즉시 닫기 (`ESC` / 바깥 클릭 닫기 지원)
  - 셀 미리보기에서 팝오버를 열지 않고도 체크박스 클릭 토글 가능
- **엑셀형 2D 선택 · 복붙 · 셀 배경색 · Undo/Redo**
  - `Shift + 방향키` 또는 마우스 드래그로 2D 직사각형 다중 선택
  - `Cmd/Ctrl + C`: 캘린더 내부에서는 2D 배치 유지 붙여넣기, 외부 메모장 등에서는 비어 있는 날짜를 제외한 `[YYYY-MM-DD]\n내용` 형식으로 출력
  - `Cmd/Ctrl + V` 기존 내용 아래에 이어붙이기(Append), `Delete`/`Backspace` 일괄 삭제, 8색 파스텔 셀 배경색 팔레트, `Cmd/Ctrl + Z / Y` 그리드 Undo/Redo
- **폴더 탭 전환 & 커스텀 날짜 포맷**
  - 상단 탭 바에서 여러 폴더 탭(`+ 폴더 추가`)을 등록하고 클릭, `Tab` / `Shift + Tab`, 또는 `Alt + 1~9`로 즉시 전환
  - 옵시디언 데일리 노트 호환 커스텀 날짜 포맷(`YYYY-MM-DD`, `YYYY/MM/YYYY-MM-DD`, `YYYY-MM-DD (ddd)` 등), 실시간 양방향 동기화, 탐색기 폴더 이동·이름 변경 시 탭 경로 자동 갱신
  - 빈 파일 생성 방지 및 내용을 전부 지웠을 때 `.md` 파일 자동 삭제
- **오프라인 한국형 달력 · 전 세계 110+개국 공휴일 & 반복 일정**
  - 대한민국 공휴일·대체공휴일·주요 기념일·음력 오프라인 내장 (`@hangukit/holidays-core` + `korean-lunar-calendar`)
  - 해외 110개국 이상 공휴일 국가 선택 지원 (무료 `Nager.Date` API 1회 조회 후 로컬 캐싱, 이후 오프라인 동작) + 사용자 커스텀 휴일·기념일(양력/음력)
  - 매일 / 매주(요일) / 매월(일자) / 매년(월·일) / 영업일 기준(매 영업일, 매월 N번째·마지막 영업일) 반복 일정 관리 (현재 탭 전용 / 모든 탭 공통 선택 가능)

## 설치 방법

### BRAT으로 설치 (권장)
1. 옵시디언 커뮤니티 플러그인에서 **BRAT**을 설치합니다.
2. BRAT 설정에서 **Add Beta Plugin**을 누르고 `jawoojo/calendar-memo`를 입력합니다.
3. 커뮤니티 플러그인 목록에서 **Calendar Memo**를 활성화합니다.

### 수동 설치
1. [GitHub Releases](https://github.com/jawoojo/calendar-memo/releases)에서 최신 릴리스의 `main.js`, `manifest.json`, `styles.css`를 내려받습니다.
2. 볼트 내 `.obsidian/plugins/calendar-memo/` 폴더에 세 파일을 복사한 뒤 옵시디언에서 플러그인을 활성화합니다.

## 개발 및 빌드

```bash
npm install
npm run build
npm test
```

로컬 옵시디언 볼트에 빌드 결과물(`main.js`, `manifest.json`, `styles.css`)을 자동 배포하려면 프로젝트 루트에 `.env` 파일을 생성해 볼트 경로를 지정하세요:

```env
OBSIDIAN_VAULT_PATH=/path/to/your/obsidian-vault
```
